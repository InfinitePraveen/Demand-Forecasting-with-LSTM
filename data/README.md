# Data

Place the Kaggle `train.csv` file in this directory.

Expected columns:

```text
date, store, item, sales
```

The repository does not include the full Kaggle dataset because it is distributed under the competition's dataset terms.

Source:
https://www.kaggle.com/competitions/demand-forecasting-kernels-only/data

Expected training file size is roughly 913,000 rows for the original challenge dataset.
