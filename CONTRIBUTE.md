# Contributing

Thanks for taking an interest in this project.

This repository is intentionally kept simple so that the forecasting workflow is easy to understand.

## How to contribute

1. Fork the repository.
2. Create a new branch.
3. Make your change.
4. Run the notebooks or test the Flask application when relevant.
5. Keep the notebook explanations clear and beginner-friendly.
6. Update `CHANGELOG.md` for meaningful user-facing changes.
7. Open a pull request with a short explanation of what changed and why.

## Good contribution ideas

- Improve the LSTM architecture without making the project unnecessarily complex.
- Add a better forecasting baseline.
- Improve evaluation or visualization.
- Improve the Flask interface.
- Fix notebook explanations or reproducibility issues.
- Improve documentation.

## Style

Please prefer readable, direct Python over clever abstractions. Keep the repository structure simple and avoid introducing a `src/` package or unnecessary helper modules unless the project requirements change.

## Pull requests

A useful pull request description should include:

- What changed
- Why it changed
- How it was tested
- Any limitations or follow-up ideas
